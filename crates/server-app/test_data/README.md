# server-app/test_data

Contains test data files and directories used for integration and unit tests in the server-app crate.

## Subdirectories
- `current-meets/`: Test data for ongoing meets (e.g., `meet_123.json`)
- `finished-meets/`: Test data for completed meets (e.g., `meet_456.json`)

## Usage
Test data is loaded by test suites to simulate real-world scenarios and validate server behavior. Files are typically in JSON format.
